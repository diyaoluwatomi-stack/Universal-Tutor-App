# 🎓 Universal Tutor
**An interactive mobile learning and translation assistant for students.**

## 🚀 Overview
Universal Tutor is a Kivy-based Android application designed to help students bridge language gaps and access educational resources on the go. This project was built to be lightweight and compatible with a variety of Android devices.

## 🛠️ Features
* **Multi-Language Translation**: Powered by `deep-translator` for real-time study help.
* **Student-Focused UI**: A clean, portrait-oriented interface built with the Kivy framework.
* **Broad Compatibility**: Optimized for devices ranging from the **Google Pixel 4a** to the **ZTE K87CA tablet**.

## 📱 Hardware Requirements
This app is designed to run efficiently on:
* **Operating System**: Android 5.0 (Lollipop) or higher.
* **Tested Devices**: Tecno Camon 16s, Google Pixel 4a, and ZTE Grand X View 4.
* **Power Note**: Works great alongside custom power solutions like **3,000Wh LiFePO4 power stations**.

## 🏗️ Technical Details
* **Language**: Python 3.
* **Framework**: Kivy.
* **Build System**: Buildozer via GitHub Actions.

## 📥 Installation
1. Navigate to the **Actions** tab in this repository.
2. Select the latest successful build.
3. Download the `package` artifact.
4. Install the `.apk` on your Android device (Enable "Install from Unknown Sources" if prompted).
